# Archive

Retired configs from the Arch (Omarchy/Hyprland), Debian, and multi-OS days. Not stowed.

- `arch/.config/` — Arch/Omarchy `~/.config` snapshot (hypr, waybar, walker, omarchy themes, fcitx, etc.) plus app configs not in use on macOS (ghostty, kitty, zed, btop, eza, fastfetch, starship, powershell, NuGet, Typora, fish, ...)
- `debian/.bashrc` — Debian bash config
- `macos-unused/.config/iterm2` — iTerm2 (replaced by Alacritty / vterm)
- `duplicates/.config/` — copies of doom/nvim that lived at the repo root (the live copies are in `macos/`). `nvim/lua/plugins/lsp.lua` here has `terraformls` commented out; the live one has it enabled.
- `old-common/setup.sh.multi-os` — previous Debian + macOS setup script
